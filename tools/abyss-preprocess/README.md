# abyss-preprocess

Config preprocessor for the `#include.abyss` config system.

## Purpose

Transforms simple DSL config files into compile-time C++ code for Abyss tools.

## Usage

```bash
abyss-preprocess \
  --app paper \
  --config-dir ~/.config/abyss \
  --output-dir /tmp/abyss-config-cache/paper \
  --generate-header build/generated/abysspaperConfigs.hpp
```

## Config Format

```cpp
// ~/.config/abyss/my-config.hpp
#include.abyss <paper>

// Strings (with shell expansion)
wallpaper = "~/Videos/wave.mp4"
name = "My Config"

// Numbers
volume = 40        // int
opacity = 0.85     // float

// Booleans
audio = true
enabled = false

// Comments
// C++ style comments are supported
```

## Generated Output

The preprocessor generates two types of files:

### 1. Processed Config (`.processed.hpp`)

```cpp
#pragma once
// Auto-generated by abyss-preprocess
// DO NOT EDIT

namespace abyss::paper::my_config {
    inline constexpr const char* wallpaper = "/home/user/Videos/wave.mp4";
    inline constexpr const char* name = "My Config";
    inline constexpr int volume = 40;
    inline constexpr float opacity = 0.85f;
    inline constexpr bool audio = true;
    inline constexpr bool enabled = false;
} // namespace abyss::paper::my_config
```

### 2. CMake Header (for build integration)

```cpp
#pragma once
// Auto-generated by abyss-preprocess

#include "/tmp/abyss-config-cache/paper/my-config.processed.hpp"

namespace abyss::paper {
    inline constexpr const char* AVAILABLE_CONFIGS[] = {
        "my-config"
    };
    inline constexpr int NUM_CONFIGS = 1;
}
```

## Features

- ✅ Type inference (no need to specify types)
- ✅ Shell expansion (`~` and `$VAR`)
- ✅ Compile-time constants (zero runtime overhead)
- ✅ Hash-based caching for incremental builds
- ✅ Multiple configs per app
- ✅ Helpful error messages with line numbers

## Integration with CMake

```cmake
include(../Abysstoolkit/cmake/AbyssConfig.cmake)

add_executable(myapp src/main.cpp)

# Add config support
abyss_add_config_support(myapp "paper")
```

This automatically:
- Runs `abyss-preprocess` before compilation
- Generates the config header
- Adds include paths
- Defines `ABYSS_CONFIG_AVAILABLE`

## Type Inference Rules

- **String**: Must be quoted with `"`
- **Bool**: `true` or `false`
- **Float**: Contains `.` (e.g., `0.85`)
- **Int**: Plain number (e.g., `40`)

## Error Handling

```
ERROR in /home/user/.config/abyss/bad.hpp:3
  Cannot infer type for value: ~/video.mp4
  Strings must be quoted: "~/video.mp4"
```

## Future Features (Not in MVP)

- Arrays: `monitors = ["DP-1", "HDMI-A-1"]`
- Nested keys: `wallpaper.DP-1 = "..."`
- Multi-line strings: `description = """..."""`
- Schema validation with helpful errors
- Config inheritance/includes

## Architecture

```
User Config (.hpp)
    ↓
abyss-preprocess (Python)
    - Parse DSL
    - Type inference
    - Shell expansion
    ↓
Processed C++ (.processed.hpp)
    - constexpr values
    - Namespaced
    ↓
CMake Integration
    - Generated header
    - Include paths
    ↓
Compile Time
    - Zero overhead
    - Type safe
```
